# DSH Studio 用户手册

## 一、快速开始

1. **安装**：运行 `DSH-Studio-Setup-<版本>.exe`，按向导完成安装（可选自定义目录；自动创建桌面/开始菜单快捷方式）。
2. **启动**：双击「DSH Studio」→ 出现鲸鱼启动页 → 数秒后自动加载 DeepSeek Harness 官方界面。
3. **首次使用**：
   - 弹出「推荐插件」对话框 → 点「安装」（插件市场 + 插件管理器，视网络速度数分钟，完成后自动重启生效；也可「暂不安装」稍后在 设置 → 安装推荐插件… 补装）；
   - 文件资源管理器与个性化外观已内置，无需安装。

## 二、配置说明

### 模型（对话前必配）

设置（左下角）→ **模型**：添加 DeepSeek 提供方 → 填入 **API 密钥**（只写存储于 `~/.dsh/.env`）→ 需要时改端点（baseURL）/模型列表 → 应用。详见《模型配置指南》。

### 插件

- **市场**：设置 → 插件 → 市场标签页：浏览/搜索/一键安装社区插件；
- **启用/停用**：插件管理器标签页；
- 卸载：管理器内卸载，或命令行 `node_modules\.bin\dsh plugin --profile web remove <包名>`（开发模式）。

### 个性化外观

设置 → **个性化外观**（独立区块）：

| 项 | 说明 |
|---|---|
| 背景 | 跟随主题 / 纯色（取色器）/ 渐变（4 套）/ 壁纸（上传本地图片）；壁纸可调**可见度**与**模糊** |
| 按键圆角 | 直角 / 默认 / 大圆角 / 全圆 |
| 强调色 | 6 款预置（主按钮/选中态变色），或恢复默认 |
| 边框样式 | 无边框 / 细线 / 强调描边 |
| 窗口边框样式 | 系统默认 / 毛玻璃（Acrylic）/ 云母（Mica），需 Windows 11 或 macOS；拖动窗口时材质临时关闭保证流畅 |

### 托盘与窗口

- 关闭窗口 → 最小化到托盘；双击托盘图标恢复；右键托盘：显示主界面 / 新建任务 / 打开设置 / 打开工作区 / 退出；
- 窗口位置/大小/最大化自动记忆（`$DSH_HOME/config.json`）；
- 任务完成且窗口在后台时，发系统通知。

## 三、数据目录

| 内容 | 位置 |
|---|---|
| API 密钥 | `~/.dsh/.env` |
| 提供方/设置 | `~/.dsh/settings.yaml` |
| 插件（profile） | `~/.dsh/profiles/web/` |
| 会话数据 | `~/.dsh/sessions/` |
| 桌面壳配置（窗口/外观/标记） | `~/.dsh/config.json` |
| 壁纸/运行时桥 | `~/.dsh/desktop/` |

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 启动报「DSH 启动失败」 | 重开一次（应用会自动修复 profile 插件登记）；仍失败看安装目录日志/控制台 `[dsh-err]` |
| 插件安装提示 pnpm/node 失败 | 开发模式需系统 Node；打包版已内置运行时。网络慢请耐心（有超时兜底与进度日志） |
| 任务栏图标不是鲸鱼 | 开发模式受 electron.exe 限制：用桌面「DSH Studio」快捷方式启动并固定到任务栏；安装版无此问题 |
| 壁纸不显示 | 确认背景选「壁纸」且已上传；把「背景可见度」调大（面板越透明壁纸越明显） |
| 毛玻璃无效果 | 需 Windows 11（Acrylic/Mica）或 macOS；面板内会提示不支持 |
| 换端口/冲突 | 应用自动选空闲端口（--port 0），无需处理 |
| 想恢复出厂外观 | 设置 → 个性化外观 → 背景选「跟随主题」、强调色选「默认」、边框「细线」、窗口「系统默认」 |
| 卸载 | 控制面板卸载 DSH Studio；用户数据在 `~/.dsh`，如需彻底清除可手动删除该目录（会同时删除官方数据，请先备份） |

## 五、更新

- 开发版跳过自动更新。
